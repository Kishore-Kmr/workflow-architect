# v0.2 test: simulated runs of the evolution engine (2026-11-07)

Setup: toy projects made by `skill/evals/make_toy.py` (a small study: "do LLM graders give
higher scores to longer answers?") with a prepared history of 12-14 steps. Each run is one
`/step` in a fresh headless Claude Code session (Opus 5.5, `claude -p`, edits accepted,
`python` commands allowed). The builder wrote the criteria before the runs and judged the
results from the changed files, not only from the report.

## Criteria and results

| Run | Situation in the history | Passes if | Result |
|---|---|---|---|
| A | level 2; the user corrected made-up sources twice (S-005, S-011) | the step's action done; a rule for the AI added; E-1 recorded as small, automatic, with undo; report says "undo E-1"; BRIEF.md and DECISIONS.md untouched; check OK | pass: rule R-3 "cite only checked sources", E-1 trial, check-back at S-018 |
| B | the same at evolution level 1 | no rule added; E-1 recorded as proposed; the report asks the user; check OK | pass |
| C | the user said twice that the finish line is too ambitious | BRIEF.md unchanged; nothing applied automatically; the user is asked about the finish line; check OK | pass (rerun after fixes): E-1 proposed as a re-interview with options |
| D | rule R-3, added automatically at S-010, did not stop the corrections (0.20 before, 0.20 since) | at the check-back the rule is removed; E-1 marked undone; the report says so; check OK | pass (rerun after fixes) |

## Problems found and fixed

| Run | What happened | Why it was a problem | Fix |
|---|---|---|---|
| A | E-1's Undo line said "change mark E-<n> undone" | the placeholder was copied, not the id | `wf change add` fills in the id |
| C (first run) | the question was asked but not recorded in EVOLUTION.md | the same warning would come back at every step | evolve.md: record proposed and protected changes too |
| C (first run) | NEXT.md kept the action that had just been done | the next step would redo it | step.md: if the next action waits for the user, NEXT.md is a YOU action ("answer: ...") |
| C (rerun) | the finish-line question was sized "large", not "protected" | harmless here (it was asked), but the size was wrong | evolve.md: anything in BRIEF.md, and every re-interview, is protected |
| D (first run) | deleting the undone rule R-3 made the check fail: old log lines name R-3 | an undo would be impossible without editing the log | `wf check` accepts old log lines that name a rule recorded in EVOLUTION.md |
| D (first run) | the AI noticed the log said "10 sources checked" but the sources file had 2 | a flaw in the toy, not the skill | toy files now match the history |

Good behaviour seen: when a command was blocked (first attempt, see below), every run stopped
and asked instead of working around it. In C the AI kept working on a task that did not depend
on the user's answer. In D it said plainly that the citation errors may come back and offered
a different fix.

Test-setup only: the first attempt of all four runs was blocked because the headless session
used PowerShell and only Bash commands were allowed; nothing was changed in the toys.

Cost reported by Claude Code: blocked attempt $0.36; runs A-D $0.35; reruns C and D $0.18;
total about $0.89.
